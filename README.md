# 💻 Universal Tech Gadget Pricing Engine (Multi-Product ML)

## 📌 Project Context & Overview
Developed as a B.Tech CSAIML Semester 1 project, this repository implements a Supervised Machine Learning regression framework to dynamically evaluate market prices for multiple tech items (Laptops and Smartphones). This mirrors pricing systems used by modern e-commerce platforms like Amazon or Flipkart.

## 🛠️ Software Stack
- **Language Stack:** Python 3
- **Algorithmic Library:** Scikit-Learn
- **Data Engineering Blocks:** Pandas

## 📊 Feature Matrix Architecture
The model evaluates pricing based on the following input features:
- `Is_Laptop`: 1 if the item is a laptop, 0 otherwise
- `Is_Smartphone`: 1 if the item is a smartphone, 0 otherwise
- `RAM_GB`: System memory capacity
- `Storage_GB`: Internal storage footprint
- **Target Variable:** `Price_INR` (Predicted Market Value)
